请求组成 ​

一个完整的 API 请求包括：

组成部分说明示例
请求方法GET 或 POSTPOST
请求地址接入地址 + 接口路径https://rak-api.raksmart.com/rakapi/v2/vps/12345/restart
请求头认证信息等X-API-Key: rpk_...
查询参数可选，用于筛选和分页?status=Active&limit=20
请求体部分 POST 接口需要，JSON 格式{"instance_id": 12345}

请求方法 ​

方法用途示例
GET查询资源GET /vps、GET /vps/12345
POST对资源执行操作POST /vps/12345/start

请求头 ​

请求头是否必需说明
X-API-Key是API Key，详见 认证方式
Content-Type有请求体时必需固定为 application/json

路径参数 ​

路径中的 {id} 表示资源标识，调用时替换为实际值。例如 GET /vps/{id} 调用时写作 GET /vps/12345。资源标识的获取方式请参见 基本信息。

查询参数 ​

查询参数附加在 URL 的 ? 之后，多个参数用 & 连接。参数值中包含空格、中文或特殊字符时，需要进行 URL 编码。

GET /vps?status=Active&region=sv2&limit=20

所有列表接口均支持 分页。各接口支持的筛选参数，请参见 在线 API 参考。

请求体 ​

需要请求体的接口，使用 JSON 格式。例如将独立云盘挂载到指定 VPS：

bash
curl -s -X POST https://rak-api.raksmart.com/rakapi/v2/volumes/23456/attach \
  -H "X-API-Key: $RAKSMART_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"instance_id": 12345}'
python
import os
import requests

resp = requests.post(
    "https://rak-api.raksmart.com/rakapi/v2/volumes/23456/attach",
    headers={"X-API-Key": os.environ["RAKSMART_API_KEY"]},
    json={"instance_id": 12345},
    timeout=30,
)
print(resp.status_code)
go
body := strings.NewReader(`{"instance_id": 12345}`)
req, _ := http.NewRequest(http.MethodPost,
	"https://rak-api.raksmart.com/rakapi/v2/volumes/23456/attach", body)
req.Header.Set("X-API-Key", os.Getenv("RAKSMART_API_KEY"))
req.Header.Set("Content-Type", "application/json")
resp, err := (&http.Client{Timeout: 30 * time.Second}).Do(req)

开机、关机、重启等操作类接口不需要请求体。
