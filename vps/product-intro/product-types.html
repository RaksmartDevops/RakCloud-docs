RakSmart 提供多种类型的 VPS 供您选择，针对不同的应用场景，可以选择不同规格的 VPS 。

实例规格 ​

规格名称说明
CPU服务器上真实存在的硬件处理器核心，拥有独立的计算单元、缓存和指令集。核心越多，并行处理能力越强。
内存内存是云服务器用于临时存储运行中的程序与数据的硬件资源，影响系统的并发能力和响应速度。
系统盘用于安装操作系统及核心运行环境的磁盘，是服务器启动和运行的基础存储介质。
数据盘独立于系统盘之外，专门用于存储业务数据、用户文件、应用数据、数据库、日志等内容的磁盘。
操作系统服务器运行的系统环境，可选类型包括：
- Linux 系统：CentOS、Ubuntu、Debian、Rocky、Almalinux；
- Windows 系统：Windows Server Datacenter 版本。
带宽类型带宽决定服务器与互联网之间的数据传输速率，直接影响访问速度。RakSmart 支持的带宽类型分为以下四类：
- 大陆优化 VIP：中国流量走电信、联通、移动一代直连线路，其他流量走国际运营商，动态优选传输路径，高峰期不绕行不拥堵，丢包率低、稳定性好。适用于面向中国用户的网站、应用、视频与业务系统；
- 精品 CN2：采用 CN2 等优质 3C 直连线路，中国流量首选三大运营商二代网络，延迟最低、抖动最小，高峰期依然保持高稳定性与连通质量。适用于金融、电商、游戏、实时交互等高要求业务；
- 大陆优化：采用三大运营商一代网络+国际线路混合，保障基础可用性与带宽规模，整体稳定性与价格兼顾。适用于普通网站、下载分发、带宽需求较高业务；
- 国际 BGP：对接国际主流运营商骨干网络，覆盖全球多地区互联，带宽资源充足，价格最具竞争力。适用于国际用户访问、大流量传输与跨境业务场景。

实例类型 ​

RakSmart 提供多种类型的 VPS 供您选择，针对不同的应用场景，可以选择不同的规格。

实例类型说明
计算型CPU 与内存的配比接近 1:1、1:2，优先保障 CPU 计算性能。适用于需要大量计算资源的业务，比如小型网站、静态页面、轻量级 API 接口、简单脚本运行。
通用型CPU 与内存的配比为 1:4（如 1 核 4G、2 核 8G），兼顾计算能力和内存容量。大多数中小型业务，比如动态网站、轻量级数据库、中小型电商平台、企业办公系统。
内存型CPU 与内存的配比为 1:8 甚至更高，重点保障内存容量。适用于需要频繁读写内存的业务，比如大型数据库（MySQL、MongoDB）、缓存服务（Redis）、数据分析平台、虚拟化桌面。

独享型实例和共享型实例 ​

类型CPU 分配策略特点适用场景
共享型实例多实例共享 CPU，实例间可能出现 CPU 资源争抢。高负载时性能可能有波动、共享计算资源、低成本对建设成本有要求的中小网站或个人场景。
独享型实例当前实例独享 CPU，实例间无 CPU 资源争抢。高性能、独享且稳定的计算/存储/网络资源、中高成本对业务稳定性有高要求的企业场景。
