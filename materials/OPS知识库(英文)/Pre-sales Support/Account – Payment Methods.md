# Account  – Payment Methods

## 1. Overview

To support convenient and secure payments, the platform provides a credit card payment method management feature.

Through this feature, users can add and manage credit card information to help ensure smooth payment for various transactions. The following sections explain the related operations and important notes for managing credit card payment methods.

## 2. Access Path

Users can navigate to Top-right profile icon → Account → Payment Methods → Add New Credit Card to enter the credit card payment management page and manage credit card information.

## 3. Operation Guide

### (1) Add a New Payment Method

#### Select Type

Choose “Credit Card” as the payment type.

#### Description (Optional)

You may add a note or description for the credit card to help identify and manage it later.

#### Enter Credit Card Number

Enter the credit card number accurately.

If the system displays the message “The card number you entered appears to be invalid. Please try again.”, please carefully verify the card number and enter it again.

#### Set Expiration Date

Enter the credit card expiration date in the Month / Year format.

#### Enter CVV/CVC2

Enter the CVV/CVC2 security code in the designated field.

If you are unsure where to find this code, click “Where can I find this number?” for guidance.

#### Select Billing Address

You can select an existing billing address or click “Add New Address” to enter a new billing address.

#### Save Changes

After confirming that all information is correct, click “Save Changes” to add the new payment method.

If you do not want to continue, click “Cancel.”

### (2) Edit and Manage Payment Information

If you need to modify existing credit card information, locate the corresponding card on the Payment Methods management page and edit the details as needed.

#### Set as Default

If multiple credit cards are available, you can set one as the default payment method. Future transactions will use this card first by default.

#### Edit

Click the “Edit” button to update information such as the expiration date or billing address, ensuring that your payment details remain accurate and valid.

#### Delete

If a credit card is no longer used for payments, click “Delete” to remove it from your account.

## 4. Important Notes

#### Information Accuracy

Please ensure that key credit card details, including the card number, expiration date, and CVV/CVC2, are entered correctly to avoid payment failures or account risks.

#### Security Protection

Please keep your credit card information secure and do not share it with others. The platform uses security measures to protect user information, but users should also remain vigilant to prevent misuse.

#### Monitor Expiration Dates

Please check your credit card expiration date regularly and update the payment method before the card expires to avoid payment interruptions.

#### Handling System Alerts

If the system displays an alert message (e.g., an invalid card number), please verify the information carefully and follow the instructions. If the issue persists, please contact customer service for assistance.

Through the credit card payment method feature, the platform provides users with a flexible and secure payment management option, helping them complete transactions more efficiently and improving the overall user experience.
