# Security – Change Password

The “Change Password” feature allows users to update their account password on the platform. Below is an overview of the feature and how to use it.

## 1. Access Path

Users can access the password change page through the following path:

Top-right profile avatar → Security → Change Password

From this page, users can update their account password.

## 2. Operation Guide

### Enter Current Password

In the “Existing Password” field, enter the password currently used for your account.

This step verifies your identity before the password is changed.

### Set a New Password

Enter your new password in the “New Password” field.

Users can also click the “Generate Password” button, and the system will automatically generate a strong password.

To improve password security, the platform recommends using a strong password with the following requirements:

- Use both uppercase and lowercase letters
- Include at least one special character, such as #, $, !, %, or &
- Avoid using consecutive characters or simple patterns

### Confirm New Password

Re-enter the new password in the “Confirm New Password” field to make sure both entries match and to avoid errors when setting the password.

### Save Changes

After completing and confirming all information, click the “Save Changes” button to finish updating the password.

If you do not want to continue, click “Cancel.”

## 3. Important Notes

### Password Security

Please make sure your password meets the platform’s strong password requirements. Avoid using simple or easy-to-guess passwords, such as birthdays or consecutive numbers, to protect your account.

### Password Consistency

When entering the new password and confirming it, make sure both entries are exactly the same. Otherwise, the password update will fail.

### Password Protection

After setting a new password, please keep it secure and do not share it with others. The platform uses security measures to protect user accounts, but users should also remain vigilant to prevent unauthorized access.

### Regular Password Updates

To further improve account security, users are advised to change their password regularly, such as every 3 or 6 months, to reduce the risk of password compromise.
