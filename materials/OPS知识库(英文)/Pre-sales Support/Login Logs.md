# Login Logs

## 1. Overview

The “Login Logs” feature is an important part of the platform’s account security management system. It provides users with detailed records of account login activity.

Through this feature, users can review their login history, monitor account activity, and identify abnormal or unauthorized login attempts in a timely manner, helping to protect account security.

## 2. Access Path

Users can access the “Login Logs” page through the following path:

Top-right profile avatar → Others → Login Logs

On this page, users can view all login records associated with their account.

## 3. Interface and Feature Description

### (1) Time Filter and Search

At the top of the page, there is a time selection field where users can select a specific date range (e.g., 2025/07/24 - 2025/07/24).

After selecting the desired time range, click the “Search” button to filter and display login records within that period, making it easier to review login activity for a specific timeframe.

### (2) Login Record List

Login records are displayed in a list format and include the following key information:

#### Date

Shows the exact time of each login attempt, including year, month, day, hour, minute, and second (e.g., 2025-07-23 10:15:56), helping users track login activity accurately.

#### Description

Displays the result of the login action, such as “User login successful”, so users can see whether the login attempt was completed successfully.

#### Username

Shows the username of the account that performed the login action.

#### Login IP Address

Records the IP address used during the login attempt. Users can use this information to determine whether the login was made by themselves or an authorized user in a familiar network environment. If an unfamiliar IP address appears, users should remain alert and check the security of their account promptly.

## 4. Important Notes

### Regular Monitoring

Users are advised to review login logs regularly, especially when any unusual account activity is suspected (e.g., unfamiliar login notifications or unexpected changes to account information).

### Handling Suspicious Logins

If unauthorized or suspicious login records are found (e.g., unknown IP addresses or unfamiliar login times), please contact the platform’s customer service immediately and request an account security check. If necessary, reset the account password to prevent unauthorized access.

### IP Address Identification

Users are encouraged to familiarize themselves with their commonly used login IP addresses so they can identify unusual login attempts more quickly. If the source of an IP address is unclear, professional IP lookup tools may be used for further verification.

### Information Protection

Login logs contain sensitive account information (e.g., login times and IP addresses). Users should keep their account login credentials secure to prevent unauthorized access to the login log page and related information.

Through the “Login Logs” feature, the platform helps users monitor account login activity, identify potential security risks in a timely manner, and improve the overall security and reliability of the account.
