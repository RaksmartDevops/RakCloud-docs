# Billing – Coupons

## 1. Feature Overview

Coupons are discount tools provided by the platform that can be used to reduce the payable amount of eligible product orders, helping users enjoy promotional savings.

The “Coupons” page under the billing module supports coupon status statistics, filtering, and usage management.

## 2. Access Path

Navigate to Customer Center → Billing → My Wallet, then click the “Coupons” tab in the top menu to enter the coupon management page.

## 3. Feature Description

### (1) Status Statistics

At the top of the page, coupons are categorized and displayed by status:

- Expiring Soon - Number of coupons approaching their expiration date
- Unused - Number of coupons currently available for use
- Used - Number of coupons that have already been applied
- Expired - Number of coupons that are no longer valid

### (2) Filters and List Information

#### Status Filter

Use the “Status” dropdown menu to quickly filter coupons by category, such as:

- All Status
- Unused
- Used

#### Coupon List Information

The coupon list displays the following key details:

**Name / Usage Details**
Shows the promotion name and specific usage rules (e.g., “December New User Promotion - $25 off orders over $100”).

**Amount / Discount**
Shows the discount amount or percentage provided by the coupon (e.g., $25 or 35%).

**Status / Renewal**
Shows the coupon’s current status (e.g., Unused) and whether it can be applied to renewal orders (e.g., Not Available).

**Time Information**
Includes the date received, expiration date, and usage date. If the coupon has not been used, the usage date will display “-”.

**Operation**
Click “Use Now” to go to the corresponding product order page, where the coupon can be applied according to its usage rules.

### (3) Usage Rules

Coupons must meet the applicable usage conditions (e.g., “New user orders over $100”) and must be used within their validity period.

Coupons that have already been used or have expired cannot be used again. Users can check the coupon status in the list to confirm whether a coupon is still valid and available.
