# Answers to Domain-Related Questions

1.How long after the domain is activated can I initiate a transfer?

- You can initiate a transfer after 60 days of activation.

2.How to add DNS records?

- To add DNS records, log in to the control panel, navigate to the "Domains" section, click on "My Domains", find the domain you want to manage, click the arrow icon at the end, select "Manage Domain Name Servers", and then click on "DNS Management". Add the DNS records in the required format.

3.Can I change the registrant's email address, and how can I do it?

- Yes, you can change the registrant's email address. If your old email address is still functional and can receive emails, provide the new email address to us, and we will make the necessary changes. You will need to verify the change using the old email address. If the old email address is no longer accessible, completing the change will result in a 60-day lock on the domain, during which transfer operations cannot be performed.

4.After domain resolution, it shows that I need to file for recordation.

- This issue arises when the domain is resolved to an IDC (Internet Data Center) service provider in mainland China without proper recordation. We are an international company, and our domain channels are international, not in mainland China. Only domains transferred to domain providers in mainland China can be recorded.

5.Domain resolution is not successful.

- You need to ensure that the domain has been successfully verified before attempting to set up DNS resolution.

6.Can I use Chinese characters when registering a domain?

- Chinese characters are not supported for domain registration, except for .CN domains.

7.After purchasing a domain, how can I use the org email?

- You can retrieve the password and log in to the platform using your rak email through the following link:http://raksmart.china.myorderbox.com/customer After logging in, click on "List Orders" > "List/Search Orders" > "Click the registered domain" > Go to the email section to activate the email. The free email service provides two email accounts with 100MB each. Domain forwarding can also be set up using the same steps, but there may be conflicts between enterprise email and domain forwarding. If you encounter any issues, you can submit a request in the support group, and we will manually enable the service. Usually, customers can use DNS resolution to point the domain to a server for website hosting, and the forwarding feature may not be necessary.

8.How long does it take for a customer's domain purchase to be approved?

- After the customer receives a verification email and clicks on the verification link, the verification process usually takes up to 72 hours.

9.Manually registered domains may not have DNS management enabled by default.

- During the domain configuration stage, make sure to select the option for DNS management.

10.Can domain names be used for CDN CNAME resolution?

- Yes, you can add CNAME records for CDN resolution.

11.Are there any limitations on domain names? If the customer's IP is blocked and they want to change the IP for resolution, is the domain locked?

- We do not have any limitations on domain names. However, when accessing websites, network firewalls may be in place. Just like how Google and Facebook are inaccessible in China, if the customer's IP is blocked, changing the IP should resolve the issue. If the domain itself is blocked, then the domain is essentially unusable.

12.How long does it take for domain configuration changes to take effect?

- It may take approximately 1 to 72 hours for domain configuration changes to take full effect.

13.How many domain names can be added to the enterprise email?

- 1 person
