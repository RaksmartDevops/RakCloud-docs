# My Wallet – Account Balance

## 1. Feature Overview

The platform’s billing module supports account top-up and balance change record inquiries, helping users clearly track account fund movements and balance status and complete fund-related operations more conveniently.

## 2. Account Balance and Recharge

### (1) Access Path

Navigate to Customer Center → Billing → My Wallet to enter the Account Balance page.

### (2) Feature Description

At the top of the page, the current account balance is displayed.

On the right side, there is an “Add Funds” button. Clicking this button will take you to the account top-up page to complete the deposit process.

## 3. Account Recharge

### Feature Description

#### Recharge Rules

- Minimum top-up amount: $1.00 USD
- Maximum top-up amount: $20,000.00 USD
- Maximum account balance limit: $100,000.00 USD

#### Operation Process

- Enter a valid amount in the “Recharge Amount” input field.
- Select a payment method from the “Payment Method” dropdown menu, such as BitPay, PayPal, or Alipay - 5.
- Click the “Add Funds” button to complete the top-up.

#### Important Notes

- Account balance withdrawals are not supported.
- Please confirm the top-up amount and payment method carefully before completing the transaction to avoid errors.

## 4. Balance Change Details

## Feature Description

### Query and Filtering

Users can filter transaction records by selecting Start Date and End Date, with quick options such as:

- Last 7 Days
- Last 30 Days

Users can also use the “Filter Status” dropdown menu to select:

- All
- Income (Funds Added)
- Expense (Funds Spent)

After selecting the desired options, click “Search” to view the corresponding transaction records.

### Transaction Details

The transaction list includes the following information:

**Transaction Date**
The exact date when the balance change occurred.

**Description**
The reason for the balance change (e.g., “Credit Applied to Invoice #XXX” indicates a payment applied to an invoice, while “Add Funds Invoice #XXX” indicates an account top-up).

**Amount**

- Positive values represent funds added (e.g., top-ups or refunds).
- Negative values represent funds spent (e.g., invoice payments).

**Credit**
The real-time account balance after each transaction is completed.

### Pagination

The bottom of the page supports pagination for viewing more transaction records.

Users can switch pages using the “Previous” and “Next” buttons.
