# 基本信息

## 接入地址

```
https://rak-api.raksmart.com/rakapi/v2
```

本文档中所有接口路径均相对于上述地址。例如 `GET /vps` 的完整地址为 `https://rak-api.raksmart.com/rakapi/v2/vps`。

## 协议

API 仅支持 HTTPS，要求 TLS 1.2 及以上版本。使用 HTTP 发起的请求将无法建立连接。

## 数据格式

| 项目 | 说明 |
| --- | --- |
| 请求体 | JSON，请求头需携带 `Content-Type: application/json` |
| 响应体 | JSON |
| 字符编码 | UTF-8 |
| 字段命名 | 字段名均为小写字母 |

## 版本

当前 API 版本为 **v2**，版本号包含在接入地址的路径中（`/rakapi/v2`）。

## 资源标识

调用接口时，需要通过 ID 指定要操作的资源：

| 资源 | 标识 | 获取方式 |
| --- | --- | --- |
| VPS、裸机云、独立服务器 | 服务 ID | 对应产品的列表接口，或 `GET /services` |
| 独立云盘 | 服务 ID | `GET /volumes` |
| 弹性 IP | 服务 ID | `GET /elastic-ips` |
| 快照 | 快照 UUID | `GET /snapshots` |

服务 ID 是一个整数，可通过上表中的列表接口获取。

::: tip 提示
一个服务 ID 对应一个具体的产品实例。例如一台 VPS 的服务 ID 为 `12345`，则查询其详情的接口为 `GET /vps/12345`。
:::
