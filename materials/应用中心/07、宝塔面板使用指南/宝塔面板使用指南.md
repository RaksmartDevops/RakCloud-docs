# 宝塔面板使用指南

## 访问应用

**面板地址**：`http://服务器IP:您配置的端口/btpanel`

**登录信息**：使用您设置的用户名和密码登录。

## 关键信息

| 项目 | 路径 |
| --- | --- |
| 网站数据 | `/opt/cloud/baota/website_data` |
| MySQL 数据 | `/opt/cloud/baota/mysql_data` |
| 虚拟主机配置 | `/opt/cloud/baota/vhost` |
| 管理脚本目录 | `/opt/cloud/baota` |
| 凭证信息 | `/opt/cloud/baota/credentials.txt` |

## 容器环境说明

> **重要**
>
> 本平台的宝塔面板运行在 **Docker 容器**中，与传统虚拟机部署方式不同。通过宝塔面板安装的应用（如 MySQL、Redis、PHP 等）均运行在容器内部，**无法在宿主机直接使用相关命令**。

### 如何执行应用命令

如果您需要在命令行中使用 MySQL、Redis 等应用的命令行工具，需要先进入容器。

1. 进入宝塔容器：

   ```bash
   docker exec -it baota /bin/bash
   ```

2. 进入容器后，即可使用容器内的命令行工具。

3. 操作完成后，退出容器：

   ```bash
   exit
   ```

> **提示**
>
> 虽然需要进入容器执行命令，但日常管理仍可通过宝塔面板的 Web 界面完成，无需频繁使用命令行。

## 命令行示例

以下示例均需先按“容器环境说明”进入宝塔容器后执行。

### 使用 MySQL 命令行

```bash
mysql -u root -p
```

### 查看 Redis 状态

```bash
redis-cli ping
```

### 查看 PHP 版本

```bash
php -v
```

## 常用操作

```bash
cd /opt/cloud/baota

./start.sh      # 启动面板
./stop.sh       # 停止面板
./restart.sh    # 重启面板
./status.sh     # 查看状态
./logs.sh       # 查看日志
```

## 常见问题

| 问题 | 解决方案 |
| --- | --- |
| 无法访问面板 | 首次部署需等待几分钟初始化，请耐心等待，可登录虚拟机执行 `/opt/cloud/baota/logs.sh` 查看日志 |
| 在宿主机执行 `mysql` 命令提示未找到 | 应用运行在容器内，需先执行 `docker exec -it baota /bin/bash` 进入容器后再使用命令 |
| 忘记宝塔面板登录密码 | 查看 `/opt/cloud/baota/credentials.txt` 文件获取初始凭证 |
