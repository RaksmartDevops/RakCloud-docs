# 账户管理 - 我的资料

## 一、概述

平台账户信息模块致力于为用户打造便捷、个性化的账户管理体验，涵盖资料维护、邮件及通知订阅等多维度设置，助力用户高效掌控账户相关内容，及时获取关键信息 。

## 二、功能详情

### （一）我的资料

用户可在此维护核心账户资料，包括姓名、地址、邮件、支付方式、语言、手机号等基础信息，这些信息是账户识别、服务适配及交易流程的重要依据，保障平台服务精准触达用户。

### （二）邮件首选项

1.**一般电子邮件**：涵盖所有与账户相关的通用邮件，是账户全流程信息传递的基础通道，如账户状态变更告知等 。

2. **账单电子邮件**：聚焦新账单生成、还款提醒及过期通知，助力用户把控财务账单节点，避免逾期风险 。
3. **工单电子邮件**：接收所有工单抄送，方便用户同步知晓工单处理进程，参与问题解决沟通，保障服务诉求闭环处理 。
4. **产品电子邮件**：聚焦产品全周期关键节点，向用户推送开通、暂停及其他周期相关通知 。无论是新功能启用、服务阶段性调整，还是周期性业务变更，都能让用户及时知晓产品状态变化，保障对产品使用的清晰掌控 。
5. **域名电子邮件：**围绕域名业务核心流程，发送注册 / 转移确认及续订通知 。从域名初始权属确立、转移过程验证，到临近到期的续订提醒，全链路覆盖域名管理关键环节，助力用户维护域名权益，避免因疏漏导致域名状态异常 。
6. **推广联盟电子邮件：**为参与推广联盟的用户打造专属通道，及时接收推广联盟相关通知，包含推广政策更新、佣金结算动态、合作活动启动等信息，助力用户紧跟联盟业务节奏，高效开展推广工作，提升收益转化 。

### （三）订阅我们的邮件

平台提供新闻、信息及特别优惠推送服务，用户只需勾选对应方框即可加入订阅，后续若想退订，也可随时操作，灵活自主管理营销信息接收 。

### （四）Telegram 通知订阅选项

1. **订单账单到期提醒**：通过 Telegram 及时推送订单账单到期信息，强化财务节点提醒，辅助用户合理安排资金 。
2. **机器交付提醒**：针对涉及机器交付场景，提前告知用户交付动态，做好收货准备 。
3. **工单回复提醒**：当工单有新回复时，Telegram 推送提醒，让用户第一时间跟进问题处理，提升沟通效率 。

## 三、保存修改

作为各功能模块设置变更后的保存入口，用户在调整 “我的资料”“邮件首选项”“订阅我们的邮件” 及 “Telegram 通知订阅选项” 等信息后，点击对应保存按钮，即可留存修改内容，确保账户信息及设置按用户需求更新生效，持续贴合个人使用习惯 。

通过上述账户信息功能，平台为用户构建起全面、可定制的账户管理体系，从基础资料到信息触达，全链路保障用户对账户的掌控力与使用体验 。
