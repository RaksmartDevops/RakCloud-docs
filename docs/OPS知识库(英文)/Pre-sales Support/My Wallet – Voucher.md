# My Wallet – Voucher

## 1. Feature Overview

Vouchers are discount credits provided by the platform that can be used to deduct a certain amount from eligible product purchases, helping users reduce service costs.

The “Voucher” page under the billing module allows users to view, filter, and use vouchers.

## 2. Access Path

Navigate to Customer Center → Billing → My Wallet, then click the “Voucher” tab at the top of the page to enter the voucher management interface.

## 3. Feature Description

### (1) Filtering and Settings

#### Status Filter

Use the “Status” dropdown menu to filter vouchers by status, including:

- All Status
- Unused
- Expired
- Used
- Inactive

#### Applicable Product Filter

Use the “Applicable Product” dropdown menu to filter vouchers by supported product type, such as:

- All Products
- VPS
- Cloud Server
- Dedicated Servers

#### Save Filter Configuration

After selecting the desired filters, click “Save Current Configuration” to save the selected conditions for easier access to the same voucher list later.

### (2) Voucher List Information

The voucher list displays the following key information:

**Name**
The promotion name or voucher identifier (e.g., “Holiday Prepaid Bonus Credit”).

**Amount**
The amount that can be deducted when using the voucher.

**Status**
The current usage status of the voucher (e.g., Unused).

**Effective Date / Expiration Date**
The valid time range during which the voucher can be used. Vouchers must be used within the validity period.

**Operation**

- **Use Now** - Redirects to the corresponding product purchase or renewal page where the voucher can be applied.
- **Transaction Records** - View detailed records related to the voucher, such as issuance and usage history.

### (3) Pagination

The bottom of the page supports pagination for viewing additional voucher records.

Users can switch pages using the “Previous Page” and “Next Page” buttons.
