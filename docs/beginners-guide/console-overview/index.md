# 了解 RakSmart 控制台

RakSmart 控制台是查看和管理 RakSmart 产品、资源与账户的统一平台，通过图形化界面即可完成资源操作、账户管理。您需要先开通 RakSmart 账号，才能访问控制台并管理相关产品。关于如何开通 RakSmart 账号请参考[注册 RakSmart 账号](注册%20RakSmart%20账号.md)。
