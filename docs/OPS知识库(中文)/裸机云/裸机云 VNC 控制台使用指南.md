# 裸机云 VNC 控制台使用指南

## 用途

本文档介绍如何通过裸机云控制台使用 VNC（Virtual Network Computing）远程连接服务器，以及 VNC 的常见使用场景和相关功能说明。

**适用产品：** 裸机云（Bare Metal Cloud）

---

## 一、什么是 VNC 控制台？

VNC（Virtual Network Computing）是一种服务器控制台连接方式，可直接访问服务器的图形控制台。

与 SSH 或远程桌面（RDP）不同，VNC 不依赖服务器的网络服务，即使 SSH 或 RDP 无法连接，也通常可以通过 VNC 登录服务器进行管理。

---

## 二、什么时候建议使用 VNC？

建议在以下场景使用 VNC：

- SSH 无法连接（Linux）
- 远程桌面（RDP）无法连接（Windows）
- 忘记服务器登录密码
- 修改服务器网络配置
- 查看服务器启动过程
- 系统无法正常启动
- 系统维护或故障排查

---

## 三、如何打开 VNC 控制台？

## 操作步骤

1. 登录 Raksmart 客户后台。
2. 进入 **产品管理** → **裸机云**。
3. 选择需要管理的服务器。
4. 点击进入 **管理** 页面。
5. 点击 **VNC** 按钮。
6. 系统将自动打开一个新的浏览器页面，并建立 VNC 控制台连接。
7. 连接成功后，即可在控制台窗口中看到服务器当前画面。
8. 使用服务器的系统账号和密码登录即可。

> **说明：**
>
> VNC 登录使用的是服务器操作系统的账号和密码（例如 Linux 的 **root** 或 Windows 的 **Administrator**），并非 Raksmart 后台账号。

---

## 四、VNC 控制台功能介绍

VNC 页面右上角提供了以下常用功能：

### 密码粘贴（Paste Password）

可将复制好的密码快速粘贴到服务器登录界面。

适用于：

- 登录密码较长或包含特殊字符；
- 避免手动输入密码时出现错误。

---

### 剪切板（Clipboard）

用于在本地电脑与 VNC 控制台之间复制和粘贴文本内容。

适用于：

- 复制命令到服务器；
- 复制服务器中的文本内容；
- 提高操作效率。

> **说明：**
>
> 剪切板主要用于文本内容的复制，不支持文件传输。

---

### 发送 Ctrl + Alt + Del

向服务器发送 **Ctrl + Alt + Del** 组合键。

适用于：

- Windows 登录界面；
- 打开 Windows 安全选项；
- 解锁 Windows 会话；
- 登录需要按 **Ctrl + Alt + Del** 的 Windows 系统。

---

## 五、VNC 可以执行哪些操作？

通过 VNC 可以完成服务器的大部分日常管理操作，例如：

- 登录服务器系统
- 修改系统密码
- 查看服务器启动状态
- 修改网络配置
- 重启服务器
- 检查系统异常
- 系统维护及故障排查

对于 Linux 系统，还可以：

- 进入单用户模式
- 修复系统配置
- 查看启动日志

---

## 六、常见问题

### Q1：VNC 登录使用什么账号和密码？

VNC 使用的是服务器操作系统的账号和密码。

例如：

Linux 默认使用 **root** 用户。

Windows 默认使用 **Administrator** 用户。

---

### Q2：为什么 SSH 或 RDP 无法连接，但 VNC 可以登录？

SSH 和 RDP 依赖服务器网络及相关服务正常运行。

VNC 直接连接服务器控制台，因此即使网络配置异常或远程服务未启动，通常仍可通过 VNC 登录服务器。

---

### Q3：VNC 可以修改服务器密码吗？

可以。

登录系统后，可按照操作系统的方式修改密码。

如果忘记服务器密码，也可以使用控制台中的 **重置密码** 功能重新设置密码。

详细操作请参考：《[裸机云密码修改与重置指南](https://billing.raksmart.com/whmcs/index.php?rp=%2Fknowledgebase%2F530%2F%E8%A3%B8%E6%9C%BA%E4%BA%91%E5%AF%86%E7%A0%81%E4%BF%AE%E6%94%B9%E4%B8%8E%E9%87%8D%E7%BD%AE%E6%8C%87%E5%8D%97.html&language=chinese-cn)》。

---

### Q4：VNC 可以复制文件吗？

不可以。

VNC 控制台提供的 **剪切板（Clipboard）** 功能主要用于复制和粘贴文本内容，不支持直接传输文件。

如需传输文件，建议使用：

- Linux：SCP、SFTP 等方式；
- Windows：远程桌面共享、FTP 或其他文件传输工具。

---

### Q5：关闭浏览器页面会影响服务器运行吗？

不会。

关闭 VNC 页面仅断开当前控制台连接，不会影响服务器的正常运行。

---

## 注意事项

⚠️ VNC 登录使用的是服务器系统账号，而不是 Raksmart 客户后台账号。

⚠️ VNC 可作为 SSH 或 RDP 无法连接时的应急管理方式，但日常管理仍建议优先使用 SSH（Linux）或远程桌面（Windows）。

⚠️ 剪切板功能仅支持文本复制，不支持文件传输。

⚠️ 如需修改系统配置或执行高风险操作，建议提前做好数据备份。
