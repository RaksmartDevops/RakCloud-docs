# 域名相关问题解答

1.域名开通后多久可以操作转移?

- 开通后的60天可以操作转移

2.如何添加DNS解析?

- 登录后台，左侧一栏找到域名，点击我的域名，找到需要解析的域名点击末尾的小箭头，点击管理域名服务器--点击DNS管理，按格式添加即可。

3.是否可以更改注册人邮箱，如何操作?

- 可以更改，如果您的旧邮箱可以正常接受邮件，您提供下新邮箱这边给您操作，您在旧邮箱内验证即可，如果您的旧邮箱无法使用，提供新邮箱操作完成后会将该域名锁定60天，期间无法操作转移。

4.域名解析后显示需要备案

- 该问题是由于客户将域名解析到中国大陆IDC服务提供商使用，未进行备案导致。

我们是国际公司，我们的域名渠道是国际，并不是中国大陆，无法备案。只有域名转入到中国大陆的域名提供商才能备案

5.域名解析不成功

- 需要核实域名是否已经验证成功，验证成功后才可以做解析。

6.注册域名，填写个人信息时是否支持中文？ 

- 除了CN域名，其他域名注册是不支持中文的

7.域名购买后    org的邮箱如何使用 

- 客户可以通过这个链接通过自己的rak邮箱找回密码并登录平台， <http://raksmart.china.myorderbox.com/customer> 
  登录以后点击罗列订单>罗列/搜索订单>点击注册的域名>定位到邮箱来激活邮箱，免费的邮箱有2个数量，每个100M 
  域名转发也可以通过上面的步骤找到，不过企业邮箱和域名转发有冲突，如果没有的话可以在群里更新一下，需要提交到后台手动开启，通常客户可以通过DNS解析将域名指向到服务器，用来做网站，所以一般转发功能也用不到

8.客户购买咱们域名后大概需要审核多久才能通过 

- 客户邮箱会收到验证邮件，里面会有验证的链接，在客户点击以后一般72小时。会验证通过

9.手动注册的域名，DNS管理可能不会自动开

- 在配置域名阶段，勾选DNS management

10.域名能做cdn的cname解析么？ 

- 是需要添加CNAME解析吗，这个没有限制的

11.域名是有什么限制吗？客户IP被墙了想替换IP解析无法调整，域名直接锁定了吗？

- 我们对域名没有限制，但是我们在访问网站的时候会经过网络防火墙，就像谷歌，facebook这些在国内打不开一样，如果客户墙掉的只是IP更换Ip即可解决，如果被墙掉的是域名，那么基本这个域名就无法使用

12.配置域名解析后多久生效？

- 域名解析完全生效需要大约1-72小时

13.企业邮箱可以添加多少个域名？

- 1个
