# 我的钱包 - 代金券

## 一、功能概述

代金券是平台提供的资金优惠工具，可用于抵扣对应产品的消费金额，帮助用户降低使用成本。财务管理模块的 “代金券” 页面支持代金券的查询、筛选及使用操作。

## 二、功能入口

通过导航路径 **客户中心 / 财务管理** 进入页面后，点击顶部标签栏的 “代金券”，即可进入代金券管理界面。

## 三、功能说明

### （一）筛选与配置

1. **状态筛选**：通过 “状态” 下拉框，可选择 “全部状态”“未使用”“已过期”“已使用”“未生效”，快速筛选对应状态的代金券。
2. **适用产品筛选**：通过 “适用产品” 下拉框，可选择 “全部产品”“VPS”“云机”“物理服务器” 等，筛选适用于特定产品的代金券。
3. **保留配置**：完成筛选条件选择后，点击 “保留当前配置” 按钮，可固定当前筛选条件，便于后续直接查看目标代金券。

### （二）代金券列表信息

列表展示代金券的核心信息：

- **名称**：代金券的活动标识（如 “双旦预充值膨胀金”）。
- **金额**：代金券的可抵扣金额。
- **状态**：代金券当前的使用状态（如 “未使用”）。
- **生效日期 / 到期日期**：代金券可使用的时间范围，需在有效期内使用。
- **操作**：

  - “去使用”：点击可跳转至对应产品的购买 / 续费页面，使用该代金券抵扣金额。
  - “交易记录”：点击可查看该代金券的使用、发放等交易明细。

### （三）分页浏览

界面底部支持分页查看更多代金券记录，可通过 “上一页”“下一页” 按钮切换页码。
