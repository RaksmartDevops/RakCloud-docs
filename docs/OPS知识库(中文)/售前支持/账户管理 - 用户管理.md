# 账户管理 - 用户管理

## 一、概述

平台的用户管理功能为用户提供了便捷的账户权限管理和新用户邀请渠道。通过用户管理界面，用户可以清晰查看已有用户的相关信息，并对其权限进行管理。同时，还能邀请新用户加入，灵活分配权限，满足团队协作或多角色管理的需求，提升账户管理的效率与安全性。

## 二、用户管理功能

### （一）功能入口

用户可通过 “后台右上角头像/用户管理” 路径，进入用户管理界面，查看和管理已有用户信息。

### （二）已有用户信息展示

在用户管理界面，以列表形式展示已添加的用户信息，包含以下关键内容：

1. **电子邮件地址**：显示用户的电子邮箱，作为用户的身份标识之一。
2. **上次登录时间**：展示用户上次登录平台的时间，帮助用户了解账户的使用活跃度。
3. **账户角色**：明确标注用户的账户角色，如示例中的 “所有者”，表明该用户对账户具有最高权限。
4. **操作选项**：针对每个用户，提供 “管理权限” 和 “移除访问” 两个操作按钮。

### （三）用户权限管理

1. **管理权限**：点击 “管理权限” 按钮，可进入对应用户的权限管理页面，根据业务需求为用户分配或调整各项操作权限，如修改账户信息、管理产品服务等（具体权限内容需根据平台实际设置）。
2. **移除访问**：若用户不再需要访问平台账户资源，点击 “移除访问” 按钮，即可解除该用户的访问和管理。

## 三、邀请新用户功能

### （一）功能入口

在用户管理界面下方，设有 “邀请新用户” 模块，用户可在此开展新用户邀请操作。

### （二）操作流程

1. **输入邮箱地址**：在输入框中填写受邀者的电子邮箱地址，确保邮箱地址准确无误。
2. **选择权限类型**：

   - **所有权限**：选择此选项，受邀者将获得较高的账户权限，可进行较多的账户操作。
   - **选择权限**：用户可根据实际需求，灵活勾选具体的权限选项，为受邀者分配定制化的权限。
3. **发送邀请**：完成邮箱地址和权限类型选择后，点击 “发送邀请” 按钮，系统将向受邀者的邮箱发送邀请链接。

### （三）受邀者处理邀请

1. **已有账户**：若受邀者已有平台账户，点击邀请链接后，可直接关联至当前账户下，按照分配的权限访问和操作相关内容。
2. **无账户**：若受邀者没有平台账户，点击邀请链接后可进行账户注册，注册完成后自动加入当前账户体系，依据分配的权限开展操作。

通过用户管理及邀请新用户功能，平台为用户构建了高效的账户协作与权限管理体系，助力用户便捷管理账户用户，灵活开展团队协作，提升账户使用的安全性与协同性。
