# 充值-支持虚拟货币转账

1.充值说明

      1.登陆后点击左则导航栏财务管理→账户充值

      2.充值限制说明：最小充值金额$10，最大充值金额$2000，余额上限金额$20000

      3.输入要充值的金额 ，如果需要使用虚拟货币转账，金额必需是$500及以上，后面会有说明

      4.选择支付方式，如果没有需要的支付方式，可随便选择一个，后面实际支付时还可以再选择

      5.点击 账户充值 即可创建充值账单并跳转到支付页面

2.支付说明

      6.支付页面可以看到要充值的账单号及金额

      7.如果选择在线支付的方式，根据页面提示完成支付即可。

          充值金额$500及以上，才可以看到USDT/USDC/BTC/ETH支付方式，选择后即可显示对应的收款地址及相关说明。

3.选择USDT/USDC/BTC/ETH支付说明

      1.虚拟货币转账需知，请您仔细阅读需知，转账视为已阅读并同意

            1.最低转账500美金；

            2.由于区块网络匿名和私密性，一旦输入错误信息，您将损失对应资产。请务必仔细核对您的充值及提币地址等相关信息，以免转账失误给您带来损失；

            3.如未收到转账或转账期间出现任何问题，Rak无法为您承担您操作失误导致的后续责任；

            4.具体入账金额和时间以我司实际收到的款项金额和财务确认时间为准，感谢您的合作与理解；

            5.虚拟货币转账后会直接入账到您在本平台的账户余额内，余额入账后不支持以任何理由任何形式进行提现，只支持本平台消费使用，请您知悉。

            6.以下信息可作为参考：

            USDC/USDT/ETH方式可以通过以下网址https://etherscan.io/  输入您的钱包address信息，查询最近交易记录进行核实您的钱包是否支持当前区块链网络和交易。

            BTC可以通过这个网址https://www.blockchain.com/  输入您的钱包address信息，查询最近交易记录进行核实您的钱包是否支持当前区块链网络和交易。
