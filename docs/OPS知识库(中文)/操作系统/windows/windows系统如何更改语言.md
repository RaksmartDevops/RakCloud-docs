# windows系统如何更改语言

1.进入控制面板，选择 时间/语言和区域 - 添加语言

![](./images/01501e143692c032.png)

2.添加语言

![](./images/5f036530d35ee6ef.png)

3.选择需要添加的语言 - 打开 - 添加

![](./images/3416041cc2cfe267.png)

4.将添加的语言上移到语言列表顶端

![](./images/d75b0a6a54998bd1.png)

5.这样还是不能直接使用的，还未进行下载安装，点击右边的选项

![](./images/1c2fd5c05d915452.png)

6.下载并安装语言包

![](./images/34ce891dbabd21a5.png)

7.下载完成后，选择高级设置

![](./images/b1d8160952cd4bce.png)

8.切换到我们刚才下载的语言，在第一个选项下拉中选择，保存即可

![](./images/4d890a3da10e666e.png)

9.完成步骤之后注销再远程连接就可以看到服务器已经切换成功
