---
title: 财务管理 - 我的账单
---

欢迎使用RakSmart客户中心。在“我的账单”页面，您可以集中查看、管理所有订单的财务记录，包括物理服务器、裸机云、VPS等产品的账单状态。以下是页面的详细功能介绍及操作指引。

---

## 一、 页面概览

在“客户中心”点击“财务管理” - “我的账单”后，您将进入账单管理列表页面。该页面以表格形式清晰展示了您名下所有账单的记录，并提供了强大的筛选与批量操作功能。

**页面顶部功能栏：**

- **筛选标签**：支持按账单状态筛选（全部 / 已付款 / 未付款 / 已取消 / 已退款 / 已过期）。
- **搜索框**：支持输入关键词（如账单号、主机名、IP地址）进行快速查询。

---

## 二、 账单列表字段详解

每一笔账单在列表中都会显示以下关键信息：

| 字段名称 | 说明 |
| --- | --- |
| **账单#** | 唯一的账单编号。点击可直接进入该账单的详情页。 |
| **主机名称** | 该账单对应订单主机名标识（如 `V20260208056951`）。 |
| **主IP地址** | 该产品分配的主IPv4地址。 |
| **账单日期** | 账单生成的日期。 |
| **过期日期** | 账单的支付截止日期。逾期未付可能导致服务暂停。 |
| **总计** | 该账单的应付金额（币种为USD美元）。 |
| **状态** | 当前账单的支付状态（如：未付款 / 已付款 / 已退款等）。 |
| **操作** | 包含对该账单的具体操作按钮。 |

---

## 三、 核心操作说明

### 1. 查看服务

- **位置**：位于账单条目的“操作”列左侧。
- **功能**：点击 **“查看服务”** 按钮，系统将自动跳转至该订单对应的**产品管理页面**。
- **适用场景**：

  - 查看服务器的硬件配置、运行状态。
  - 进行重启、重装系统、修改密码等运维操作。
  - 管理该产品的附属服务。

### 2. 查看账单

- **位置**：位于账单条目的“操作”列右侧。
- **功能**：点击 **“查看账单”** 按钮，将直接进入该笔账单的**详细账单页面**。
- **适用场景**：

  - 核对账单明细（如续费、升级、额外IP费用等）。
  - **支付单笔账单**：在该页面可直接通过支付网关完成付款。

### 3. 批量付款

- **位置**：位于账单列表的**最底部**。
- **功能**：提供合并支付功能，方便您一次性处理多笔账单。
- **操作步骤**：

  1. 在账单列表中，勾选您需要支付的所有账单（通常仅支持勾选状态为“**未付款**”的账单）。
  2. 点击列表底部的 **“批量付款”** 按钮。
  3. 系统将自动跳转至结算中心，汇总您勾选的所有账单金额，生成一张合并支付单。
  4. 您只需一次支付，即可完成所有选中账单的缴费。

---

## 四、 状态说明

- **已付款**：账单已完成支付，对应服务正常运行或已续费成功。
- **未付款**：账单待支付。请在过期日期前完成付款，以免服务中断。
- **已退款**：该笔交易已发起退款，金额将原路返回至您的支付账户。
- **已取消**：该账单已被取消（通常由于订单关闭或管理员操作）。
- **已过期**：账单已超过支付截止日期，未支付。对应的服务可能已被暂停。

---

**提示：**

- 如果您的账单列表较长，可以使用页面右上角的 **“显示”** 下拉菜单，调整每页显示的记录数（如10条/页、20条/页）。
- 如有任何账单疑问，可点击右侧的 **“在线联系客服”** 获取帮助。
