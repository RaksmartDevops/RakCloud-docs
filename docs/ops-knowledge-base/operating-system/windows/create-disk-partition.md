---
title: Windows系统如何创建分区
---

1.在Windows Server桌面，左下角开始菜单中右键点击磁盘管理

![](./images/4f9298053e92e412.png)

2.在磁盘管理对话框中，选择操作 > 重新扫描磁盘，查看未分配的磁盘容量

磁盘0（C盘）为系统盘，磁盘1（D盘）为数据盘

![](./images/105c3be7100c454f.png)

3.右键单击磁盘1未分配的空白处，并选择新建简单卷

![](./images/d04db36772432595.png)

4.对磁盘进行容量大小分配，默认是全部的空间

![](./images/55a9b481394ad197.png)

5.选择新建分区的驱动号

![](./images/a2523da918e0a948.png)

6.默认下一步，完成即可

![](./images/6f284570b83c2b85.png)

7.创建完成后，可以看到新增的D盘。
