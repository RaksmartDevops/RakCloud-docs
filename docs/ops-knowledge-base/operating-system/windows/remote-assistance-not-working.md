---
title: Windows系统无法启用远程协助
---

Windows Server系统在开启远程协助时，会出现远程协助灰色并无法选中开启的情况

1. 1.单击Winodws任务栏的服务器管理器

**![image](./images/87ecb0f2bafb3a52.png)**

2. 2.在弹出的服务器管理器窗口，单击右侧添加角色和功能。

**![image](./images/78076ff0a06eddfa.png)**

3. 3.在弹出的添加角色和功能向导中，单击下一步直到功能设置部分，找到并选中远程协助，单击下一步直到完成。

**![](./images/96ea92ab2ee037af.png)**
