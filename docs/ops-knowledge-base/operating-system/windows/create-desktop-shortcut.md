---
title: Windows系统如何设置图标快捷方式
---

部分安装完的Windows系统，远程登录系统后桌面只有一个回收站图标，很多用户反馈此电脑、控制面板、查找比较麻烦，设置为快捷方式在桌面会方便些。

如何设置桌面快捷方式，具体操作如下：

1.点击左下角图标打开开始菜单



2.右击控制面板，点击打开文件位置

![](./images/37f433ebda0a1071.png)

3.右击控制面板，点击发送到，在点击桌面快捷方式

![](./images/a425da80552fbf6d.png)

4.“这台电脑”的快捷方式步骤也是一样

![](./images/5387fe271eaf57fc.png)
