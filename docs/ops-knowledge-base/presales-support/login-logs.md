---
title: 登录日志
---

## 一、概述

平台登录日志功能是账户安全管理的重要组成部分，为用户提供了全面、详细的登录行为记录。通过该功能，用户可以清晰了解账户的登录动态，及时发现异常登录情况，有效保障账户安全，同时也便于用户对自身登录行为进行回顾与管理。

## 二、功能入口

用户可通过后台右上角头像/其他，进入 “登录日志” 界面，查看登录记录。

## 三、界面与功能说明

### （一）时间筛选与查询

界面上方设有时间选择框，用户可选择特定的时间范围（如示例中的 2025/07/24 - 2025/07/24），然后点击 “查询” 按钮，即可筛选出该时间段内的登录记录，方便用户针对性地查看特定时期的登录情况。

### （二）登录记录列表

登录记录以列表形式展示，包含以下关键信息：

1. **时间**：精确记录每次登录的具体时间，包括年、月、日、时、分、秒（如 2025-07-23 10:15:56），帮助用户准确掌握登录时间点。
2. **描述**：显示登录操作的结果，如 “用户登录成功”，明确告知用户该次登录是否顺利完成。
3. **用户名**：展示进行登录操作的账户用户名，让用户清楚是哪个账户发生了登录行为。
4. **登录 IP**：记录登录时所使用的 IP 地址，用户可通过 IP 地址判断登录操作是否为本人或授权人员在熟悉的网络环境下进行，若发现陌生 IP 地址的登录记录，需提高警惕，及时核查账户安全。

## 四、注意事项

1. **定期查看**：建议用户定期查看登录日志，特别是在发现账户异常情况（如收到陌生登录通知、账户信息疑似被篡改等）时，应及时通过登录日志核实登录行为，以便采取相应的安全措施。
2. **异常登录处理**：若在登录日志中发现非本人或未授权的登录记录（如陌生的登录 IP、未知的登录时间等），请立即联系平台客服，说明情况并申请账户安全核查，必要时可对账户密码进行重置，防止账户信息泄露或被盗用。
3. **IP 地址识别**：用户应了解自己常用的登录 IP 地址范围，以便在查看登录日志时快速识别异常 IP。若对某些 IP 地址的来源存疑，可通过专业的 IP 查询工具进行溯源，进一步确认登录行为的安全性。
4. **信息保管**：登录日志包含用户账户的敏感信息（如登录时间、IP 地址等），用户需妥善保管账户登录凭证，防止未授权人员访问登录日志界面，获取相关信息。

通过登录日志功能，平台为用户构建了一道坚实的账户安全防线，助力用户实时监控账户登录动态，及时发现并处理潜在的安全风险，全面提升账户使用的安全性与可靠性
