## 用途

本文档介绍 VPS 弹性 IP（Elastic IP）的功能说明、适用场景及后台操作方法，帮助客户了解弹性 IP 的绑定、解绑及使用注意事项。

**适用产品：**

- VPS（Virtual Private Server）

---

## 一、什么是弹性 IP（Elastic IP）

弹性 IP（Elastic IP，简称 EIP）是一种可独立管理的公网 IP 地址，可根据业务需求绑定或解绑 VPS 实例，实现公网 IP 的灵活管理。

与实例默认公网 IP 不同，弹性 IP 可以独立于实例进行管理，方便业务迁移或网络调整。

**适用场景：**

- 为 VPS 增加独立公网 IP。
- 更换服务器时重新绑定公网 IP。
- 根据业务需求灵活管理公网 IP。

---

## 二、进入弹性 IP 管理页面

登录 Raksmart 客户后台。

依次进入：

**产品管理 → VPS  → 弹性 IP**

进入页面后，可查看当前账户下所有弹性 IP，包括：

- IP 地址
- 所属区域
- 所属线路
- 当前状态（已绑定 / 空闲）
- 当前绑定实例（如已绑定）

---

## 三、绑定弹性 IP

当弹性 IP 处于空闲状态时，可绑定至指定 VPS。

### 操作步骤

1. 登录 Raksmart 客户后台。
2. 进入 **产品管理 → VPS → 弹性 IP**。
3. 点击进入需要绑定的弹性 IP。
4. 点击 **分配**。
5. 在实例列表中选择需要绑定的 VPS。
6. 确认绑定。

绑定完成后，系统会自动重启 VPS，使新的网络配置生效。

> **说明：**
>
> 绑定弹性 IP 会导致服务器自动重启，请提前做好业务安排。

---

## 四、解绑弹性 IP

如需解除弹性 IP 与当前 VPS 的关联，可执行解绑操作。

目前支持两种解绑方式：

### 方式一：在弹性 IP 页面解绑

1. 进入 **产品管理 → VPS → 弹性 IP**。
2. 找到已绑定的弹性 IP。
3. 点击 **空闲**。
4. 确认操作。

解绑完成后，弹性 IP 将恢复为空闲状态，可用于后续重新绑定。

> **说明：**
>
> 解绑弹性 IP 同样会导致服务器自动重启，请提前确认业务允许中断。

---

## 五、绑定规则

弹性 IP 并非可以绑定任意 VPS，需满足以下条件：

- 弹性 IP 与 VPS **必须属于同一地区（Region）**。
- 弹性 IP 与 VPS **必须属于同一网络线路**。

例如：

- 美国洛杉矶国际 BGP 的弹性 IP，只能绑定美国洛杉矶国际 BGP 的 VPS。
- 日本大陆优化线路的弹性 IP，不能绑定日本国际 BGP 线路的 VPS。

如果服务器与弹性 IP 不满足上述条件，在绑定页面中将**不会显示该服务器**，因此无法完成绑定。

---

## 六、使用建议

建议在以下场景使用弹性 IP：

- 需要灵活管理公网 IP。
- 业务迁移至新的 VPS。
- 更换服务器后继续使用原有公网 IP。
- 统一管理多个公网 IP。

如无需更换公网 IP，可继续使用实例默认公网 IP。

---

## 七、常见问题

### Q1：为什么绑定页面看不到我的 VPS？

通常是因为弹性 IP 与 VPS 不属于同一地区或同一线路。

请确认：

- 地区（Region）是否一致。
- 网络线路是否一致。

仅满足上述条件的 VPS 才会显示在绑定列表中。

---

### Q2：绑定弹性 IP 会影响服务器运行吗？

会。

绑定完成后，系统会自动重启服务器，使网络配置生效。

建议提前停止业务或选择业务低峰期进行操作。

---

### Q3：解绑弹性 IP 会重启服务器吗？

会。

解绑完成后，系统同样会自动重启服务器。

---

### Q4：解绑后弹性 IP 会释放吗？

不会。

解绑后，弹性 IP 将恢复为空闲状态，仍保留在当前账户下，可继续绑定符合条件的 VPS。

---

### Q5：为什么绑定成功后仍无法访问？

建议检查以下内容：

- VPS 是否已完成重启。
- 安全组或系统防火墙是否已放行相关端口。
- SSH（Linux）或 RDP（Windows）服务是否正常运行。
- 域名解析是否已更新（如使用域名访问）。

---

## 注意事项

⚠️ 弹性 IP 与 VPS 必须属于**同一地区、同一线路**，否则无法绑定。

⚠️ 如果绑定页面未显示目标 VPS，请优先确认地区及线路是否一致。

⚠️ 绑定、解绑弹性 IP 均会导致服务器自动重启，请提前做好业务安排。

⚠️ 解绑后的弹性 IP 不会被释放，而是恢复为空闲状态，可再次绑定至符合条件的 VPS。
