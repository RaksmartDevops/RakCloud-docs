title: 物理服务器控制面板
---

## **一、获取面板管理密码**

登录平台，进入**用户中心**，点击 \*\*“我的产品与服务”**，找到目标服务器并进入**“产品详情”**页面。在 “服务器信息” 标签页下的 “软件信息” 区域，找到**“面板管理密码”\*\* 项，点击密码对应的 “\*” 号，即可显示面板管理密码。

![](./images/313_88f0e15a-6dc4-4fe5-b362-63d20ffe8b59.png)

## **二、登录 DCIM 服务面板**

打开浏览器，访问 [https://dsclient.raksmart.com](https://dsclient.raksmart.com/ "https://dsclient.raksmart.com")，进入 DCIM 服务面板登录界面。在登录界面中，用户名输入机器的**主 IP**，密码输入之前在后台获取到的面板管理密码，完成登录。

## **三、服务器操作**

登录 DCIM 服务面板后，您可以对这台物理服务器进行多种操作，包括**开机**、**关机**、**重启**等，方便您对服务器进行远程管理与维护。
