---
title: 产品概述
---

VPS（Virtual Private Server，虚拟专用服务器）是通过虚拟化技术将一台物理服务器分割成多个独立、隔离的虚拟服务器。

### 基本概念

使用 VPS 之前，您需要了解以下概念：

 <table width="100%">
   <tr style="text-align: left;">
     <th width="25%">概念</th>
     <th width="75%">说明</th>
   </tr>
   <tr>
     <td>实例</td>
     <td>VPS 实例（VPS Instance） 是指用户通过 RakSmart 平台购买并创建的独立虚拟服务器运行实体，是用户实际操作、部署业务的核心载体。能提供高性能的计算资源，包含 CPU、内存、操作系统、网络等基础的计算组件。</td>
   </tr>
   <tr>
     <td>操作系统</td>
     <td>管理服务器硬件资源和软件程序的系统软件。支持多种 Linux 发行版本和 Windows 版本。</td>
   </tr>
  <tr>
     <td>独立云盘</td>
     <td>独立云盘（Independent Cloud Disk）是 RakSmart 官方推出的独立块存储产品，可挂载至VPS、裸机云 等计算实例，作为数据盘使用。</td>
   </tr>
    <tr>
    <td>弹性 IP</td>
     <td>弹性 IP（Elastic IP，简称 EIP）是云计算环境中一种可独立申请、动态绑定 / 解绑、可保留的公网 IP 地址。可以在不同实例间灵活迁移，不随实例的创建、释放而改变。</td>
  </tr>
  <tr>
    <td>安全组</td>
    <td>一种虚拟防火墙，是一个逻辑上的分组，可以将同一地域具有相同网络安全隔离需求的 VPS 加到同一个安全组内。</td>
  </tr>
  <tr>
    <td>区域和可用区</td>
    <td>- RakSmart 区域是指在全球范围内划分的、具备独立基础设施的地理部署单元。不同地域之间完全隔离，以保证所提供服务的稳定性与容错性。<br>- RakSmart 可用区是同一区域内物理隔离的独立数据中心单元。同一可用区内实例之间的网络时延更小，用户访问速度更快。</td>
  </tr> 
</table>
