### 实例类型

RakSmart 提供多种类型的 VPS 供您选择，针对不同的应用场景，可以选择不同的规格。

<table width="100%">
        <tr style="text-align: left;">
          <th width="20%">实例类型</th>
          <th width="80%">说明</th>
        </tr>
  			<tr>
          <td>计算型</td>
          <td>CPU 与内存的配比接近 1:1、1:2，优先保障 CPU 计算性能。适用于需要大量计算资源的业务，比如小型网站、静态页面、轻量级 API 接口、简单脚本运行。</td>
        </tr>
         <tr>
          <td>通用型</td>
          <td>CPU 与内存的配比为 1:4（如 1 核 4G、2 核 8G），兼顾计算能力和内存容量。大多数中小型业务，比如动态网站、轻量级数据库、中小型电商平台、企业办公系统。</td>
  			 </tr>
         <tr>
          <td>内存型</td>
          <td>CPU 与内存的配比为 1:8 甚至更高，重点保障内存容量。适用于需要频繁读写内存的业务，比如大型数据库（MySQL、MongoDB）、缓存服务（Redis）、数据分析平台、虚拟化桌面。</td>
        </tr>  			
      </table>
