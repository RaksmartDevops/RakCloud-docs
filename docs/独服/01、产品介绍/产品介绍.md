# 产品介绍

## 产品简介

RakSmart 物理服务器 是为用户提供专属物理硬件资源的高性能计算设备，用户可独占整台服务器的 CPU、内存、存储、网络等全部资源，拥有物理硬件的原生高性能与稳定可靠性，同时支持按需定制硬件配置、搭配多样化网络线路与安全防护方案，适配对物理性能、数据隔离、业务稳定性有严苛要求的场景。

## 产品优势

RakSmart 物理服务器基于独占硬件资源与全球网络优势，为各类高性能、稳定性要求严格的业务场景提供可自定义、高可靠性的物理服务器解决方案，兼顾性能、灵活性与全球部署能力。

- **独享物理资源**

  每台物理服务器均独享完整硬件资源，无资源争抢或虚拟化损耗。提供 BIOS 级访问权限，实现对服务器的完全掌控。适用于数据库、高吞吐量服务、实时计算与高并发任务等对性能和响应速度有严格要求的核心业务。

- **可深度定制**

  提供丰富的硬件扩展选项，从入门级 E3 到高性能 E5 / Gold / Platinum 甚至 AMD EPYC 系列，可按需定制服务器配置。支持多种存储选项（HDD / SSD / NVMe ）及带宽组合，构建适配不同业务场景的专属服务器。轻松适配大规模应用、数据密集型任务与特殊场景。

- **全球高速网络**

  支持多线路选择，覆盖全球访问，可为跨地域业务提供低延迟与更稳定的访问路径。TB 级带宽输出，支持高吞吐、高并发与大流量业务，确保网络稳定与业务连续性。

- **全面安全保护**

  物理服务器提供天然隔离的资源边界，有效避免邻居干扰风险。配合可选 DDoS 防护等网络安全策略，保障业务在突发攻击与流量波动下持续稳定运行，提升系统安全性与可靠性。

- **可视化管理**

  支持通过集中化 Console 控制台或 API 远程管理物理服务器资源，结合资源监控、日志与告警能力，帮助 IT 团队快速掌握运行状况并优化基础设施配置，提高运维响应效率。

- **灵活付费方案**

  提供从入门级到旗舰级多种硬件规格，并支持灵活账期（按月 / 按年），多配置与灵活账期组合，满足不同预算需求，有效控制企业 IT 成本。合理的定价策略使得物理服务器解决方案在性能与成本间建立最佳平衡。

## 产品类型

不同业务场景对服务器的硬件配置、网络带宽、防护能力等需求不同。为适配多样化的业务需求，RakSmart 将物理服务器按核心功能与应用场景划分为多种类型。同种类型，还可根据 CPU、内存、存储等配置，分为不同的规格。您可根据不同的业务需求选购不同的产品类型和规格。具体分类如下：

---

### 大带宽物理服务器

提供高达40Gbps 带宽选项，适配视频直播、下载站、高流量业务场景，支持带宽弹性升级。

---

### 多IP物理服务器

提供从 1~512 多 IP 选项，适合 SEO 优化、多站点部署等场景，IP 段分布合理且支持自定义配置。

---

### 高防物理服务器

提供高达 T级 DDoS 防护能力，保障高风险业务，如游戏、金融的稳定运行。

---

### GPU 物理服务器

提供 NVIDIA Tesla P100、NVIDIA Tesla V100、NVIDIA HGX A100 8-GPU SXM、4090 等型号的 GPU 服务器。

---

### 定制物理服务器

支持按需定制硬件配置，如 CPU 型号、内存容量、硬盘类型等，满足大数据运算等高性能需求。

## 区域和可用区

本文介绍 RakSmart 物理服务器支持的全部区域和可用区。

### 区域

区域是指在全球范围内划分的、具备独立基础设施的地理部署单元。不同地域之间完全隔离，以保证所提供服务的稳定性与容错性。RakSmart 物理服务器目前支持的区域有美洲、亚洲和欧洲。

- 不同区域的服务器默认不能通过内网通信。

- 如果不同区域之间的服务器之间有通信需求，可以通过公网 IP 进行通信。

---

### 可用区

可用区是同一区域内物理隔离的独立数据中心单元。同一可用区内实例之间的网络时延更小，用户访问速度更快。

### 如何选择区域和可用区

用户与资源部署地域的距离越近，网络时延越低，访问速度越快。建议您根据业务场景对时延的要求选择区域和可用区。

> **重要**
>
> 购买并开通 RakSmart 物理服务器资源后，无法更换区域和可用区。

#### 如何选择区域

在购买 RakSmart 物理服务器时，请结合以下因素合理选择区域。

1. 地理位置

   一般情况下建议选择和您目标用户所在区域最为接近的数据中心，可以进一步提升用户访问速度。

2. 资源价格及资源覆盖

   不同区域的资源规格和产品覆盖可能有差异，请根据您的需求及预算选择合适的区域。

3. 产品之间的关系

   如果多个 RakSmart 产品一起搭配使用，需要注意：不同区域的主机、存储、负载均衡等服务，内网不互通。

#### 如何选择可用区

在同一区域内，各可用区之间可以实现故障隔离，即如果一个可用区出现故障，则不会影响其他可用区的正常运行。

- 目标用户地理位置：选择在地理位置上最靠近目标服务用户的地域，以防止出现访问时延，影响访问速度。

- 容灾部署：如果购买的物理服务器位于同一个地域，建议将业务分散部署在多个可用区，以确保故障隔离，实现跨可用区容灾。
