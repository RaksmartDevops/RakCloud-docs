---
title: API 简介
---

RakSmart Cloud API 是 RakSmart 提供的 RESTful 接口，用于以编程方式查询和管理账户下的云资源。通过 API，您可以将 RakSmart 的资源管理能力集成到自有系统、运维脚本或监控平台中。

## 适用场景

- **自动化运维**：通过脚本批量执行开机、关机、重启等操作。
- **资源巡检**：定期获取服务列表和实例状态，接入自有监控或告警系统。
- **系统集成**：在内部管理平台中展示和操作 RakSmart 资源。

## 支持的产品与能力

| 产品 | 查询 | 操作 |
| --- | --- | --- |
| VPS | 列表、详情、可用区域 | 开机、关机、重启、强制关机、强制重启 |
| 裸机云 | 列表、详情、可用区域 | 开机、关机、重启、强制关机、强制重启 |
| 独立服务器 | 列表、详情、可用区域 | 开机、关机、重启 |
| 独立云盘 | 列表、详情、可用区域 | 挂载、卸载 |
| 弹性 IP | 列表、详情、可用区域 | 绑定、解绑 |
| 快照 | 列表、详情 | 恢复 |
| 服务 | 列表、详情 | — |
| 账户 | 账户信息 | — |

各接口的完整说明请参见 [在线 API 参考](https://rak-api.raksmart.com/)。

## API 与控制台的关系

API 与 RakSmart 控制台操作的是同一批资源，通过 API 执行的操作会同步反映在控制台中，反之亦然。API 仅能访问调用者本人账户下的资源。
