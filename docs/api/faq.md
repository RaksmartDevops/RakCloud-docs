## 返回 401，如何排查？

请依次检查：

1. 请求头名称是否为 `X-API-Key`。
2. API Key 是否完整，以 `rpk_` 开头，没有多余的空格、换行或引号。
3. API Key 是否与控制台 **API Key** 页面显示的一致。
4. 环境变量是否正确加载，可以先打印 Key 的前几位确认，但不要打印完整 Key。

详见 [认证方式](./authentication/api-key.md)。

## 资源在控制台可以看到，为什么 API 返回 404？

常见原因：

- **接口与资源类型不匹配**：例如将独立服务器的服务 ID 用于 `/vps/{id}`。请使用与产品对应的接口，或先通过 `GET /services` 确认服务类型。
- **API Key 属于其他账户**：API 只能访问 API Key 所属账户的资源。

## 操作返回 204，但资源状态没有变化？

`204` 表示指令已下发，操作需要一定时间完成。请等待片刻后查询资源详情。如果长时间没有变化，请登录控制台查看，或提交工单。详见 [异步操作](./general/async-operations.md)。

## 返回 409 是什么原因？

资源当前的状态不允许执行该操作，例如服务已暂停，或弹性 IP 已绑定到其他实例。请根据 `error_message` 和资源当前状态处理。详见 [HTTP 状态码](./general/status-codes.md#_409-状态冲突)。

## 返回 429 怎么办？

请求频率超过了限制。请降低请求频率，等待后重试。详见 [请求频率限制](./general/rate-limits.md)。
