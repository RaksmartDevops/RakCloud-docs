---
title: 安全最佳实践
---

API Key 等同于您账户的操作凭证。获得 API Key 的人可以对您账户下的资源执行关机、重启等操作。请遵循以下建议，保障账户安全。

## 仅在服务端使用

API Key 只应在您可控的服务器或运维环境中使用。

- **不要**在网页前端（JavaScript）、移动应用或桌面客户端中嵌入 API Key，这些环境中的代码可以被他人查看。
- 如需在网页中展示资源信息，请由您自己的后端服务调用 API，再将结果返回给前端。

## 妥善保存

- 使用环境变量、配置文件（并限制文件权限）或专业的密钥管理服务保存 API Key。
- **不要**将 API Key 直接写在代码中，也不要提交到 Git 等代码仓库。
- **不要**通过邮件、即时通讯工具或工单明文发送 API Key。

## 泄露后的处理

如果怀疑 API Key 已经泄露：

1. 立即提交工单，联系管理员处理。
2. 登录控制台检查资源状态，确认是否有非预期的操作。

## 最小化分发

API Key 可以操作账户下的全部资源。请仅将 API Key 提供给确实需要的系统和人员。
